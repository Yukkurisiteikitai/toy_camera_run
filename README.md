# Liquid Motion Archive

カメラ映像や動画ファイルの動きを検出し、その変化をインクのように画面へ堆積させる WebGL 実験です。Three.js とシェーダーを使って、動きの差分、色の注入、にじみ、紙の質感を合成しています。

## 推奨ファイル

最新版は `custom_index.html` です。

主な機能:

- カメラ映像から動きを検出して描画
- ローカル動画ファイルの読み込み
- インク色の変更
- 色の混ざり具合の調整
- 描画内容のクリア
- ハンバーガーメニュー内に設定画面を収納
- 全体表示モード
- `Esc` で全体表示を終了

## 使い方

ブラウザで `custom_index.html` を開きます。

カメラを使う場合は、ブラウザのカメラ許可が必要です。うまく動かない場合は、ローカルサーバー経由で開いてください。

```sh
python3 -m http.server 8000
```

起動後、以下にアクセスします。

```text
http://localhost:8000/custom_index.html
```

## 操作

- 右上のハンバーガーメニュー: 設定画面を開閉
- `Video Source`: ローカル動画を読み込み
- `Ink Color`: インク色を変更
- `Color Mix`: 選択色の混ざり具合を調整
- `Camera`: カメラ入力に戻す
- `Clear`: 現在の描画をリセット
- `全体表示`: UI とハンバーガーアイコンを隠して表示
- `Esc`: 全体表示を終了

## ファイル

- `custom_index.html`: 最新版。設定 UI、動画読み込み、全体表示に対応
- `ok_next.html`: フレームレート依存と黒くなりがちな色味を調整した版
- `osya.html`: 元になった実装
- `color_ful.html`: 色味を強めた試作版
- `clade_colorful.html`: デバッグ表示付きの試作版
- `index.html`, `tes.html`: 以前の実験ファイル
- `bug.md`: 修正方針のメモ

## 注意点

- Three.js は CDN から読み込んでいるため、初回表示にはインターネット接続が必要です。
- カメラはブラウザや実行方法によって許可されない場合があります。その場合はローカルサーバー経由で開いてください。
- 動画ファイルはブラウザで再生できる形式を選んでください。
